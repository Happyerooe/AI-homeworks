一、项目简介

本系统是一款基于AI技术的智能作业批改工具，专为批改数学英语作业设计。
老师只需上传学生作业照片、输入参考答案，系统即可自动完成：

- 手写文字识别（OCR）：识别作业图片中的手写内容
- 智能批改：调用大模型对比学生答案与参考答案，自动判分
- 个性化评语：针对每份作业生成有针对性的评语
- 薄弱点分析：定位学生的知识薄弱环节

核心理念：不漏一题，不落一人 —— 让每个学生都被认真对待。


二、技术栈

Web界面：Gradio（快速构建演示界面，无需前端知识）
OCR识别：PaddleOCR（百度开源OCR引擎，支持中英文手写识别）
AI批改：DeepSeek API（大语言模型，负责判分、评语生成、薄弱点分析）
开发环境：Python 3.8+（全部代码使用Python编写）


三、项目结构

homework_grader/

四、快速开始

1. 环境准备
确保你的电脑已安装 Python 3.8 或更高版本。
检查方法：打开终端（或命令提示符），输入：
python --version
如果显示 Python 3.8.x 或更高，说明已安装。

2. 安装依赖
在项目文件夹下打开终端，执行：
pip install -r requirements.txt
首次安装可能需要几分钟，请耐心等待。

3. 配置 API Key
本系统调用 DeepSeek API 进行智能批改，你需要：
(1) 访问 DeepSeek Platform（https://platform.deepseek.com/）注册账号
(2) 进入「API Keys」页面，创建一个新的 API Key
(3) 打开 grader.py 文件，将以下代码：
    api_key = os.environ.get("DEEPSEEK_API_KEY", "请在此填入你的API Key")
    改为：
    api_key = "sk-你的真实API Key"
安全提醒：请勿将包含真实 API Key 的代码提交到公开仓库！

4. 运行系统
在项目文件夹下打开终端，执行：
python app.py
终端会显示一个本地地址，类似：
Running on local URL:  http://127.0.0.1:7860
在浏览器中打开该地址，即可使用系统。


五、使用指南

步骤一：上传作业照片
点击「上传作业」区域，选择一张学生作业的图片（支持 jpg、png 格式）。

步骤二：输入参考答案
在「参考答案」文本框中，输入该道题的标准答案。

步骤三：开始批改
点击「开始批改」按钮，系统会自动执行：
(1) OCR 识别图片中的手写文字
(2) 调用大模型对比学生答案与参考答案
(3) 生成得分、评语和薄弱点分析

步骤四：查看结果
页面下方会展示：
- 识别结果：OCR 从图片中提取的文字内容
- 得分：0-100 分
- 评语：个性化反馈，包含优点、问题、改进建议
- 薄弱点分析：简洁指出学生的知识薄弱环节

七、常见问题

Q1：运行 pip install 时报错怎么办？
把报错信息复制到 Trae 的 AI 对话框中，说“安装依赖报错了，帮我解决”，AI 会给出修复方案。

Q2：OCR 识别结果不准怎么办？
确保图片清晰、光线充足；尽量让手写字迹工整；可以多试几张不同角度的照片。

Q3：API 调用失败怎么办？
检查以下几点：API Key 是否正确填写；网络是否正常；DeepSeek 账户是否有余额。

Q4：系统支持哪些学科？
当前 Demo 版本已测试数学题批改。通过调整参考答案和 Prompt，也可以用于语文、英语等学科的作业批改。
